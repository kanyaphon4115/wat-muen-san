# Cultural map artwork

The page uses existing temple/chedi/statue images from this project temporarily where the precise reference assets are absent. These are contextual illustrations, not verified photographs of each listed location. Add the original artwork under these names to replace them automatically; no duplicate source files are needed.

- `wat-muen-san.png`: central temple illustration / transparent cutout
- `h1-cow-statue.jpg`: white cow statue
- `h2-chedi.jpg`: white and gold chedi
- `h2-temple.jpg`: temple thumbnail
- `h2-tiger-statue.jpg`: tiger statue thumbnail
- `h2-viharn.jpg`: viharn thumbnail
- `h3-japanese-museum.jpg`: Japanese memorial museum
- `h4-gallery.jpg`: gallery interior
- `h5-silverware.jpg`: silverware display
- `wat-muen-san-sunset.jpg`: sunset temple photograph for the bottom section

The exact reference images have not been supplied. Layout and interactions are implemented separately from the image assets.

Configure `PLACES_TIKTOK_URL` in the running application's `.env` with the intended HTTPS clip/account URL. Until provided, the TikTok button announces that its link is not yet configured; it never opens an invented destination.
